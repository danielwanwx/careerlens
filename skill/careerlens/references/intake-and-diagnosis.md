# Intake and diagnosis

Collect only inputs that can change a decision:

1. target role family or representative target description;
2. authorized resume, portfolio, work sample, or structured stories;
3. location, horizon, and weekly preparation capacity;
4. optional company, level, work mode, compensation, authorization, and
   interview-stage constraints.

Mark inputs `present`, `missing`, `stale`, or `contradictory`. A profile URL is
not candidate evidence until its authorized content is available. A target
description establishes requirements but cannot establish candidate proof.

For each capability, record the requirement, current evidence state, compact
candidate-owned reference, evidence needed to change the state, and an
observable completion check. Do not convert missing detail into a low numeric
score. Use an input gate until the minimum evidence is sufficient.
